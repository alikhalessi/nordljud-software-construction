# Condition B — God Mode Agentic Coding

Test whether a capable AI coding agent, given a deliberately strong master prompt and broad engineering autonomy, can independently generate engineering practices commonly enforced through SDD.

- Start independently from the **same** frozen common baseline.
- Agent may autonomously clarify requirements, plan, specify, design, implement, test, reflect and verify.
- Do not prohibit the AI from generating specifications; spontaneous structure is part of the observed outcome.
- Do not explicitly impose the Spec Kit workflow on this condition.
- Preserve the master prompt, actual agent actions, interventions, evidence, and results.
- Freeze/tag when the defined time window ends.
