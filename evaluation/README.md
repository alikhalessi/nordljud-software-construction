# Independent evaluation

The **same** evaluation protocol will be applied to each frozen implementation.

Candidate measures (must be operationalized and fixed before coding):
- MVP requirements fulfilled / partial / missing
- Functional test pass/fail and defects
- Login, progression, persistence, playback and A2–C1 paths
- Elapsed human time, prompts, interventions and rework
- Testing/documentation evidence, maintainability, traceability
- Spontaneous agent-generated planning/specification/verification behaviour

Distinguish objective test results from subjective assessments. Record development constraints and threats to validity, including prior familiarity and single-run variability.
