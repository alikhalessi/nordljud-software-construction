# Condition C — Explicit Specification-Driven Development (SDD)

Build the same Nordljud MVP from the same common baseline using a deliberately imposed specification-first workflow, provisionally with GitHub Spec Kit.

Possible phases (subject to the actual installed toolkit): constitution, specify, clarify, plan, tasks, analysis, implementation, verification.

- Record specs, decisions, tasks, verification and requirements traceability.
- Keep scope, shared data and evaluation protocol consistent with Conditions A and B.
- Preserve original prompts, tool outputs, failures and human corrections.
- Freeze/tag at the defined time limit, even if incomplete.

**Status:** Not started.
